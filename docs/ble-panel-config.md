# 蓝牙设置墨水屏（本地 BLE）

设备长按按键约 1.2 秒或双击后，15 分钟内同时开放原 Wi-Fi 配置页和 BLE 配置服务。三击保留手动刷新功能。BLE 广播名为 `J-Calendar Config`，墨水屏显示本次随机生成的六位配对码。配对须建立加密且已认证的连接，配置写入特征要求认证；配置窗口关闭后 BLE 停止广播，屏幕恢复原页面。

## 使用步骤

1. 将包含本功能的 z21 固件烧录到设备。
2. 等待普通页面刷新结束，再按住设备按键至少 2 秒后松开（或双击）；三色墨水屏全刷约需 25～30 秒，期间页面看似没有反应，完成后会显示六位配对码。
3. 在支持 Web Bluetooth 的电脑浏览器中运行 `python3 -m http.server 8766 --bind 127.0.0.1 --directory tools`，打开 `http://127.0.0.1:8766/jcalendar-ble-config.html`。Web Bluetooth 需要安全上下文；同机的 localhost 可用于本地开发，普通局域网 HTTP 地址不适用。
4. 点击“连接设备”，选择 `J-Calendar Config`，按系统提示输入墨水屏上的配对码。
5. 页面读取设备的面板配置后，选择显示模板，编辑课程或待办，点击“保存模板并刷新墨水屏”。设备保存成功后关闭配置窗口，并刷新首页。

网页也保留原有 Wi-Fi、天气参数的 BLE 设置。手机浏览器是否支持 Web Bluetooth 取决于浏览器和系统；不支持时仍可使用设备 Wi-Fi 热点的 `/panel` 配置入口。本页不经云端、不上传配置。

## 协议与限制

- 服务 UUID：`1d8b0c01-95b2-4fe8-b74d-8db8f9937e01`；配置特征 UUID：`1d8b0c02-95b2-4fe8-b74d-8db8f9937e01`。
- 写入帧：`0x01` + 标志位（首帧 `0x01`，末帧 `0x02`）+ 最多 180 字节 JSON 片段；通知帧以 `0x02` 开头，标志位相同。
- 面板操作：`{"op":"get_panel"}` 读取；`{"op":"set_panel","config":{...}}` 保存。`config` 与 Wi-Fi 面板的版本 1 JSON 契约一致，调用同一校验及 NVS 保存逻辑。
- 请求最大 4096 字节。网页写入按 18 字节 JSON + 2 字节帧头分片，兼容默认 ATT MTU 23（单次特征写入最多 20 字节）；不再依赖浏览器与设备协商更大的 MTU。长配置传输仍需在目标浏览器与硬件上验证。
- 设备正常休眠期间不广播 BLE；不会因蓝牙扫描自动唤醒。配对码不通过未认证的 GATT 接口提供。
