# Phase 1：本地面板管理

本分支在已有 AP 配置机制上增加手机优先的课程表、待办与模板选择。后台运行在 ESP32 上，无需电脑常驻，也不需要手机 App。

## 使用

1. 首次开机自动进入配网；已有配置时，按现有固件的双击手势进入配置窗口。
2. 手机连接热点 `J-Calendar-Setup`，密码 `JCalendar`，访问 `http://192.168.4.1/`（以设备实际 AP 地址为准）。
3. 在设备设置中保存 Wi-Fi，重新打开配置窗口后进入“课程表、待办与显示模板”。
4. 也可在配置窗口内使用同一 Wi-Fi 下的设备 IP 访问 `/panel`。IP 会输出到串口。
5. 选择日常看板、今日课程或待办。保存成功后退出配置窗口并刷新屏幕。

配置窗口为 15 分钟，设备其余时间仍遵循原深度睡眠策略；后台不会全天在线。局域网暂不提供 mDNS 域名。AP 与局域网端口同时可用；仅适合可信网络及持有设备的用户，不要映射到公网。

## 当前范围

- 配网、天气、用量和电源配置沿用原有实现。
- 待办最多 12 条，支持完成与删除；显示前 8 条未完成任务，超过时最后一行提示总数。
- 课程最多 35 条，按星期编辑；屏幕显示设备本地日期对应的课程，按录入顺序排列。
- 每条内容最多 60 UTF-8 字节（通常约 20 个汉字），屏幕按实际像素宽度截断，保留完整后台内容。
- 配置使用版本 1 JSON，单个 NVS 字符串保存；校验失败不写入，写入失败返回错误。
- 本地内容不依赖天气/用量服务，断网仍可显示。课程日期依赖正确的设备时钟，时钟未初始化时显示校时提示。
- 不包含学期、单双周、课程导入、任务截止日期/优先级、远程账号、管理密码和实时像素预览。

## 接口

- `GET /panel`：内嵌管理网页，无外部脚本、字体或 CDN。
- `GET /api/panel`：读取配置。
- `POST /api/panel`：JSON 保存，需 `X-Panel-Request: 1`。浏览器跨域请求无 CORS 放行。

```json
{"version":1,"layout":"courses","tasks":[{"text":"整理书包","done":false}],"courses":[{"day":1,"text":"08:00 数学 A101"}]}
```

## 验证与实物验收

构建：`python -m platformio run -e z21`。默认 z21 为仓库当前默认的 4.2 英寸屏幕；其他硬件环境尚需分别验证。

浏览器回归：安装 Playwright 及其 Chromium 后运行 `node test/browser/panel_admin.cjs`。脚本覆盖 375、430、1280 像素宽度、文本安全渲染、待办勾选、星期切换和保存请求。

烧录前需成功构建；烧录后验收首次配网、已配置网络中的 AP/LAN 双入口、保存/断电重启/离线保留、星期切换、任务完成后消失、超过 8 行提示、窗口关闭及睡眠、原天气用量页面和日历切换。
